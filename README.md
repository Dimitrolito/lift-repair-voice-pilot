# Тестовий голосовий помічник ліфтової служби

Локальний прототип для перевірки українського сценарію приймання заявки без телефонного номера та CRM.

## Запуск

Потрібен Node.js 20 або новіший.

```sh
npm start
```

Відкрийте адресу, яку покаже термінал. Для розпізнавання мовлення потрібен браузер із Web Speech API (рекомендовано актуальний Chrome) і доступ до мікрофона. Браузер може обробляти розпізнавання через свій зовнішній сервіс. Після натискання кнопки заявка зберігається в localStorage цього браузера.

Це демонстрація діалогу, а не диспетчерська система. Не використовуйте для реальних аварійних звернень або реальні контактні дані. Аудіофайл не створюється; розпізнавання виконує браузер, не GPT.

## Наступний етап

Після перевірки сценарію додати серверну сесію OpenAI Realtime/GPT-Live з ключем у змінній середовища. Не зберігати ключ у браузері або репозиторії. Потім інтегрувати вхідну телефонію через SIP.
